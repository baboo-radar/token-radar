Token Radar ranks pre-token DeFi protocols by the implied value of the token each may issue one day (TVL × category comps × momentum × anticipation), with a step-by-step farm plan for every row, in an offline dark-radar dashboard with board, detail and filter views.

## Run it

```sh
mkdir -p /tmp/tr-out && MAKEFUN_OUTPUT_DIR=/tmp/tr-out node main.ts --input /path/to/snapshot.json
```
